Classroom Render Farm

A classroom tool that lets the computers in a school media lab render Blender animation frames together.

What it does

The teacher sends a Blender shot to the farm. Each lab computer, running the free Blender software that is already installed, renders a few frames and returns them. The teacher collects the finished frames. Jobs can be scheduled for evenings and weekends.

How it uses Google Drive

The farm stores its jobs (Blender files, footage used by the shot, and rendered frames) in one folder, Classroom Farm, in the Google Drive account that runs the farm. It uses Google's drive.file permission, which only allows it to see and change files the farm itself created. It cannot see any other files in that Drive.

Who it is for

It is run by a teacher for their own class and is not a public service. There is no sign-up and no advertising.
